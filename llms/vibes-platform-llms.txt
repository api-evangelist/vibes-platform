- [Android Wallet Templates API](https://developer-platform.vibes.com/reference/android-wallet-templates-api.md)
- [Create the Google Wallet template](https://developer-platform.vibes.com/reference/post_companies-company-key-campaigns-wallet-token-wallet-template.md): Create the Google Wallet (Android) pass template for a wallet campaign. Field semantics follow Google Wallet generic passes (https://developers.google.com/wallet/generic). Many text fields accept Liquid personalization tags that are replaced per recipient.
- [Update the Google Wallet template](https://developer-platform.vibes.com/reference/put_companies-company-key-campaigns-wallet-token-wallet-template.md): Update the Google Wallet (Android) pass template for a wallet campaign.
- [Get the Google Wallet template](https://developer-platform.vibes.com/reference/get_companies-company-key-campaigns-wallet-token-wallet-template.md): Retrieve the Google Wallet (Android) pass template for a wallet campaign. Each campaign has a single Google Wallet template.
- [iOS Wallet Templates API](https://developer-platform.vibes.com/reference/ios-wallet-templates-api.md)
- [Create the Apple Wallet template](https://developer-platform.vibes.com/reference/post_companies-company-key-campaigns-wallet-token-passbook-template.md): Create the Apple Wallet (iOS) pass template for a wallet campaign. Field semantics follow Apple Wallet Passes (https://developer.apple.com/documentation/WalletPasses). Many text fields accept Liquid personalization tags that are replaced per recipient.
- [Update the Apple Wallet template](https://developer-platform.vibes.com/reference/put_companies-company-key-campaigns-wallet-token-passbook-template.md): Update the Apple Wallet (iOS) pass template for a wallet campaign.
- [Get the Apple Wallet template](https://developer-platform.vibes.com/reference/get_companies-company-key-campaigns-wallet-token-passbook-template.md): Retrieve the Apple Wallet (iOS) pass template for a wallet campaign. Each campaign has a single Apple Wallet template.
- [Get store locations](https://developer-platform.vibes.com/reference/get_companies-company-key-campaigns-wallet-token-locations.md): List the store locations attached to a wallet campaign. Results are paginated; use the `page` and `page_size` parameters to page through them.
- [Bulk create store locations](https://developer-platform.vibes.com/reference/post_companies-company-key-campaigns-wallet-token-locations-bulk.md): Add store locations to a wallet campaign in a single request (up to 1000 per call). The `Idempotency-Key` header is required: repeating a request with the same key returns the original result without inserting duplicates.
- [Delete a store location](https://developer-platform.vibes.com/reference/delete_companies-company-key-campaigns-wallet-token-locations-id.md): Remove a single store location from a wallet campaign.
- [Delete all store locations](https://developer-platform.vibes.com/reference/delete_companies-company-key-campaigns-wallet-token-locations-delete-all.md): Remove store locations from a wallet campaign in bulk. Optional filters limit which locations are deleted; omit them to delete every location on the campaign.
- [Get the location selector](https://developer-platform.vibes.com/reference/get_companies-company-key-campaigns-wallet-token-location-selector.md): Retrieve the branded "Add to Wallet" landing page configuration for a wallet campaign.
- [Create the location selector](https://developer-platform.vibes.com/reference/post_companies-company-key-campaigns-wallet-token-location-selector.md): Create the branded "Add to Wallet" landing page for a wallet campaign.
- [Update the location selector](https://developer-platform.vibes.com/reference/put_companies-company-key-campaigns-wallet-token-location-selector.md): Update the branded "Add to Wallet" landing page for a wallet campaign.
- [Delete the location selector](https://developer-platform.vibes.com/reference/delete_companies-company-key-campaigns-wallet-token-location-selector.md): Remove the location selector from a wallet campaign.
